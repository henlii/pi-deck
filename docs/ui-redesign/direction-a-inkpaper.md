# A · 墨纸工作台

## 定位

把 Pidance 设计成一张有秩序的数字工作桌：不是聊天气泡堆叠，而是用户与 Pi 共同维护的一份工作记录。暖灰、墨色和珊瑚红带来区别于常见蓝紫 AI 产品的辨识度。

## 视觉与排版

- 桌面布局采用 `260px / minmax(560px, 1fr) / 300px` 三栏，边界以细线而非大面积色块表达。
- 标题建议 **Fraunces** 或 **Newsreader**，正文建议 **IBM Plex Sans**，代码使用 **IBM Plex Mono**；产品实现可自托管字体。
- 用户消息是右侧短笺，Pi 回复保持无气泡的文档排版，减少长回答的视觉噪声。
- 珊瑚红只用于当前项、主按钮和关键进度；成功／警告仍使用独立语义色。

## 组件决策

- 最近会话置于项目树之前，以三条紧凑记录呈现，并保留项目名帮助跨项目辨认。
- 工具卡片像“执行票据”：左侧状态轨、命令摘要、文件变更和耗时组成固定扫描路径。
- 右栏使用 Files／Git／Info 分段标签；文件树密度略高于聊天区。
- 设置采用左侧分类、右侧表单的纸张式对话框；主题卡直接预览颜色和层级。

## 浅深模式

浅色是本方案的主呈现，深色变体使用温暖的炭黑而非纯黑，保留纸张层次。两者都使用同一珊瑚强调色；具体变量见 `theme-tokens.md`。

## 动效建议

首屏只做一次 180–260ms 的分栏错峰淡入；工具运行时状态轨缓慢流动。避免消息逐条弹跳，保证阅读稳定。
