# C · 磷光终端

## 定位

为终端重度用户提供高对比、高密度但不粗糙的界面。它不是复古终端皮肤，而是把终端的可扫描规则移植到现代网页工作台。

## 视觉与排版

- 使用严格的 8px 网格、直角或 2px 小圆角、编号区段和强边框。
- 全局建议 **Berkeley Mono**（需商业许可时改用 **Commit Mono**）或 **IBM Plex Mono**；品牌标题可搭配 **Chakra Petch**。
- 磷光绿用于活动与主动作，琥珀用于警告，青色用于链接和信息；避免整页荧光泛滥。
- 消息角色通过左侧标签、时间戳和分隔线表达，不依赖聊天气泡。

## 组件决策

- 最近会话固定为 `RECENT` 区段；项目／工作树／会话使用可预判的文本缩进与树线。
- 工具调用默认单行状态，展开后展示等宽输出；文件改动使用 `+/-` 数字而非大色块。
- 右栏像检查器，Files／Git／Info 以命令标签切换。
- 移动端保留终端表达，但所有点击目标至少 44px，底栏使用文字加简图标，避免只有符号。

## 浅深模式

深色为主；浅色采用“打印纸终端”风格——灰白底、墨黑字、深绿色强调。高对比模式可在此主题上额外提高边框和焦点环，而不是作为另一套主题。

## 动效建议

仅保留光标、运行指示器和区段切换三类动效，均遵守 `prefers-reduced-motion`。不加入扫描线动画，避免疲劳与可访问性问题。
