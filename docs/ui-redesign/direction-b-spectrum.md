# B · 光谱舱

## 定位

面向多任务、高频切换的开发者，把 Pidance 塑造成有空间纵深的“任务舱”。深靛蓝是主场，青绿色是运行状态，紫色只用于智能相关的轻微光晕。

## 视觉与排版

- 桌面使用窄功能轨 + 会话栏 + 主工作区 + 上下文栏，形成清晰层级；窄轨只承载全局入口，不发明新功能。
- 标题建议 **Space Grotesk**，正文建议 **Manrope**，代码使用 **JetBrains Mono**。
- 半透明仅用于面板层次，正文区域保持实色，避免玻璃效果损害代码可读性。
- 页面背景加入低对比径向光晕，视觉焦点停留在活动会话和输入框。

## 组件决策

- 最近会话做成横向“任务胶囊”，桌面位于会话栏上部，移动端进入会话抽屉。
- 工具调用强调过程：状态节点、耗时、改动文件、输出摘要形成一条可展开的执行轨迹。
- 通知从输入框上方出现，和当前执行上下文绑定，不遮挡顶部导航。
- 移动端顶部显示项目／分支上下文，底栏负责四个一级区域。

## 浅深模式

深色是主呈现；浅色不是简单反白，而是偏冷的雾白与深靛文字。青绿强调在两种模式中均经过对比度调整。

## 动效建议

会话切换时使用 220ms 横向淡移；工具状态节点只在运行时呼吸。背景光晕保持静止，减少 GPU 消耗和注意力干扰。
